## 🇬🇧 English
**Ahir Yönetim** is a responsive, web-based management platform built as a **Progressive Web App (PWA)**. It is entirely crafted using vanilla web technologies, ensuring a lightweight and incredibly fast user experience.

### ✨ Key Features
- 📱 **PWA Support**: Installable on desktop and mobile devices with Service Worker integration.
- ⚡ **Blazing Fast**: Zero heavy frameworks; pure HTML, CSS, and JS.
- 🌐 **Offline Mode**: Works seamlessly even without an internet connection using caching strategies.

### 🚀 Getting Started
Simply open `index.html` in any modern web browser or serve it via a local server to test the PWA installation prompts.

## 🇹🇷 Türkçe
**Ahir Yönetim**, **Progresif Web Uygulaması (PWA)** standartlarında geliştirilmiş duyarlı (responsive) bir yönetim platformudur. Tamamen temel web teknolojileri kullanılarak yazılmış olup, hafif ve inanılmaz derecede hızlı bir kullanıcı deneyimi sunar.

### ✨ Temel Özellikler
- 📱 **PWA Desteği**: Service Worker entegrasyonu sayesinde bilgisayar ve mobil cihazlara yüklenebilir.
- ⚡ **Şimşek Hızında**: Ağır framework'ler kullanılmadı; sadece HTML, CSS ve JavaScript.
- 🌐 **Çevrimdışı Modu**: Önbellekleme stratejileri sayesinde internet bağlantısı olmadan da sorunsuz çalışır.

### 🚀 Başlangıç
Uygulamayı denemek için `index.html` dosyasını modern bir tarayıcıda açabilir veya PWA yükleme özelliklerini test etmek için yerel bir sunucu (localhost) üzerinden çalıştırabilirsiniz.
