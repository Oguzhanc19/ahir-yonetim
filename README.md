# Ahir Yönetim

## English
Ahir Yönetim is a web-based Progressive Web App (PWA) designed for management purposes. Built purely with HTML, CSS, and Vanilla JavaScript, it offers a seamless and responsive user experience with offline capabilities.

### Technologies
- HTML5 & CSS3
- Vanilla JavaScript
- PWA (Service Workers, Manifest)

---

## Türkçe
Ahir Yönetim, yönetim amaçlı tasarlanmış web tabanlı bir PWA (Progresif Web Uygulaması) projesidir. Sadece HTML, CSS ve saf JavaScript ile oluşturulmuş olup, çevrimdışı çalışma özellikleriyle kesintisiz ve duyarlı bir kullanıcı deneyimi sunar.

### Teknolojiler
- HTML5 & CSS3
- Saf (Vanilla) JavaScript
- PWA (Service Workers, Manifest)
